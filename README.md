# Flaive — Releases

Public APK releases for **Flaive** (Android).

> Personal project for educational and research use. The app ships with **no built-in music sources** — it starts as an empty shell and runs source extensions inside a sandbox you control.

Grab the latest build from the [Releases](https://github.com/HDShinobi/flaive-releases/releases) tab.

Source code: [HDShinobi/flaive](https://github.com/HDShinobi/flaive). This repository hosts signed APK builds only.
