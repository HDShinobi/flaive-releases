# Lossless Music Download — Releases

Public APK releases for **Lossless Music Download** (Android).

> Personal project for educational and research use. The app ships with **no built-in music sources** — it starts as an empty shell and runs source extensions inside a sandbox you control.

Grab the latest build from the [Releases](https://github.com/HDShinobi/lossless-music-releases/releases) tab.

The application source is private. This repository hosts signed APK builds only.

Built on a fork of [SpotiFLAC-Mobile](https://github.com/spotiflacapp/SpotiFLAC-Mobile) (MIT © zarzet).
